# 留白 · 浏览器新标签页

基于 React 19、TypeScript、shadcn/ui（Radix UI + Tailwind CSS）的 Manifest V3 新标签页扩展，适用于 Chrome 和 Edge。界面参考 iTab 的混合网格：网站和设置占一格，待办、随手记占 2×2 格；没有主页侧栏。

## 本地开发

需要 Node.js 22.12+ 和 pnpm 11。

```sh
pnpm install
pnpm dev
```

默认开发地址为 `http://127.0.0.1:5173/`。

```sh
pnpm lint
pnpm test
pnpm build
pnpm verify:extension
```

构建会生成 `dist/` 和 `blank-new-tab-1.0.0.zip`，包含全部脚本、样式与 PNG 扩展图标，不依赖远程脚本或字体。网站图标从网站自身加载，用户上传的图标保存在本机。

## 加载扩展

1. 执行 `pnpm build`。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
3. 开启开发者模式，点击「加载已解压的扩展程序」，选择本项目的 `dist` 文件夹。
4. 打开新标签页；如果浏览器询问是否保留新标签页变更，选择保留。

ZIP 是分发包；本地加载前先解压，或直接使用 `dist`。修改代码后重新构建，在扩展管理页点击刷新，再重新打开新标签页。扩展不申请浏览历史、标签页或账号权限；首次读取网站名称与图标时，会请求用户输入站点的可选访问权限。

## 使用

- **待办**：在小组件底部直接输入，Enter 添加；文字可就地修改，复选框完成任务。标题或展开按钮打开完整清单。删除与清理已完成项均提供撤销。
- **随手记**：点击标题、备忘条目或新建按钮打开编辑器，支持标题、多段长文本、自动保存、删除和撤销。
- **网站与图标**：通过「添加图标 → 添加网站」创建入口，输入网址后自动读取真实网站名称与站点图标，默认使用站点图标。图片占满图标区域并等比显示，外围负责圆角裁切，没有额外的小 favicon 底板。图标来源可选网站图片、文字、上传图片和原有系统预设；编辑时可保留当前图片。文字支持中文和英文，单行居中，较长内容自动缩小，图标文字与网站名称独立。未取得网站图片时可以使用文字图标；读取与图片加载失败均明确显示。背景色支持预设、自定义色和透明；上传图片保留原图，支持浏览器可解码的 SVG、PNG、JPG、WebP、GIF 等图片。读取请求直达用户输入的站点，不经过第三方解析服务，不携带账号 Cookie。
- **分组**：通过「添加图标 → 新建分组」创建。可勾选将全部网站收进一个分组，也可将网站拖到分组上，或从网站右键菜单选择移动位置。解散分组会保留其中的网站。
- **系统预设图标**：提供 135 个 Lucide 通用图标，涵盖导航、办公、开发、学习、交流、影音设计、生活、自然健康和实用工具九类，支持中文、英文与关键词搜索。选择器使用紧凑的纯图标网格，每页最多展示 48 个，悬停可查看名称，支持预设色和自定义颜色。图标随扩展打包，无需联网获取；旧存档中的 GitHub、Figma、Notion 图标继续保留。
- **分组预览与点击**：1×1 显示四个缩略图；2×1、1×2 分别横排、竖排三个；2×2 显示前三个大图标，并将后续最多四个缩略图组合在右下角；4×2 最多显示八个大图标。内部图标始终保持正方形，窗口、间距和尺寸变化时按实际容器重新排布。2×2 的前三个大图标和 4×2 的大图标可直接打开网站，遵循「在新标签页打开网站」设置；缩略图、空白区域或分组名称打开完整分组。拖动空白区域或分组名称可移动整个分组。预览未显示的网站仍保留在分组中。
- **移动与尺寸**：网站和小组件共用可定位网格，空白格也能放置，支持移动到最右侧。网站和分组右键可选择 1×1、2×1、1×2、2×2、4×2 五档布局；分组默认为 2×2，并显示内部网站缩略图。小组件从头部拖动，底部没有额外文字。右键小组件可选择 2×2、3×2、3×3、4×2、4×3 五档尺寸，调整后自动安置冲突的图标。拖动时直接移动原图标或卡片，松手后直接落格，不重复播放从原位置到目标位置的动画。位置和尺寸都会保存。键盘聚焦后按 Space 抓起，方向键移动，Space 放下，Escape 取消。分组内的网站也可排序和调整尺寸。
- **自适应槽位与分页**：桌面和分组共用有边界的槽位网格，按可用宽高确定每页容量，放不下时分页，不通过拖动撑出滚动条。只有多页时才显示分页。拖动停在本页边缘；需要跨页时，将鼠标停在分页箭头上，或使用 PageUp / PageDown。窗口缩小、放大时分别读取对应网格的布局，窄窗口中的移动、改名不会覆盖已有宽屏坐标。图标超过当前页容纳尺寸时会按可用槽位收缩显示，回到大窗口恢复所选尺寸。
- **整理**：「设置 → 常规 → 整理桌面图标」按当前窗口槽位重新排列，并提供撤销。该操作只修改当前网格尺寸的布局，适用于旧版本已经丢失原排列的情况。
- **设置**：点击网格中的「设置」图标打开右侧面板。常规偏好、主题与壁纸、备份都在这里。「主题与壁纸 → 外观模式」可选择纯白、纯黑或跟随系统；选择会保存，卡片和弹窗统一使用中性灰阶。默认「纯净」背景随模式切换为 #FFFFFF 或 #000000。壁纸提供前端定义的纯色、渐变和用户上传图片，不提供图库。
- **图标外观**：「设置 → 图标」调整默认圆角或圆形、图标大小、圆角半径、不透明度、横纵间距、名称显示、名称字号与颜色，以及图标区域最大宽度。名称默认跟随桌面文字颜色，适应纯黑、纯白和图片壁纸；自定义后使用所选颜色。默认图标为 60px、圆角 18px、间距 30px、名称 12px。分组内图标和缩略图也使用这些外观设置。
- **弹窗与抽屉**：设置抽屉不渲染遮罩、不模糊背景，也没有向桌面扩散的阴影，可以直接预览桌面。普通弹窗使用 Radix Dialog，只做短暂淡入淡出，不缩放或位移。分组在首次绘制前完成槽位测量，关闭动画期间保留内容；高度随内容调整，超过屏幕可用高度后分页。名称使用弹窗主题色，独立于桌面自定义名称颜色。分组预览容器采用随黑白主题变化的中性色背景。
- **桌面半透明表面**：搜索框、小组件和分组使用半透明底色，不对壁纸实时做背景模糊，避免相邻图标悬浮缩放时出现白块或绘制残影。
- **搜索**：支持必应、Google、百度；点击搜索框左侧切换。页面非编辑状态下按 `/` 聚焦搜索。搜索是用户主动提交后才打开第三方搜索服务。

## 数据

工作区和上传图片保存在当前浏览器、当前扩展的 IndexedDB 中，无需账号或服务器。保存失败会明确提示并提供重试，不会用默认数据覆盖读取失败的存档。清除扩展数据、卸载扩展或清理浏览器站点数据可能移除这些内容，建议在设置中导出备份。

JSON 备份包含待办、备忘、图标来源、文字图标、上传图标原图、分组、不同网格尺寸的桌面与分组布局、网站与组件尺寸、图标外观、其他偏好和壁纸图片。导入先校验结构与网站协议，再展示替换确认；错误文件不会替换当前工作区。旧存档会补齐新增图标设置并保留原有网站、预设图标和内容。开发站点与正式扩展属于不同来源，数据不互通，可通过备份迁移。

「设置 → 数据备份 → 导入备份」也支持 Infinity v2 的 `.infinity` JSON 文件。多页网站按原顺序合并，保留分组、图片图标、文字图标与背景色；随手记的 HTML 转成文本，保留文字、换行与修改时间。内置应用和非网页链接会列在导入预览中；壁纸、天气、搜索和界面设置不迁移，保留当前留白设置。当前样例的待办为空；含非空 Infinity 待办的文件会明确报错并取消导入，待确认其实际结构后再支持。确认替换后可通过提示撤销。

## 代码结构与扩展组件

```text
src/
  background.ts                 读取站点网页的扩展后台
  App.tsx                       页面、面板状态与组件注册
  components/
    shortcuts/icon-grid.tsx     网站、分组、组件的混合网格与拖拽
    shortcuts/shortcuts.tsx     网站和分组编辑
    widgets/                   待办、备忘与公共组件容器
    settings-dialog.tsx        设置面板
    wallpaper-panel.tsx        壁纸选择、上传
    ui/                        shadcn 风格的 Radix 基础组件
  hooks/use-workspace.ts        读取、保存状态与错误显示
  lib/workspace.ts              数据模型和分组操作
  lib/storage.ts                IndexedDB 与备份
public/manifest.json            MV3 新标签页声明
scripts/package-extension.mjs   生成扩展图标与 ZIP
scripts/verify-extension.mjs    检查构建包、CSP 与本地资源
scripts/site-metadata-plugin.ts 开发与预览时的真实站点读取接口
```

后续新增小组件时，在 `widgets/` 内独立实现组件，并在 `App.tsx` 的 `widgets` 列表注册唯一 `id`、名称、`sizeKey` 和内容；在尺寸模型中声明预设后，网格会处理占位、拖拽和位置持久化。业务数据与操作保存在 `workspace.ts` 和相应组件内，不放进网格基础层。

动画使用 Motion 的页面与弹窗过渡，以及 CSS 的悬停和面板进出动画。桌面拖动只让其他图标让位，小组件内部不播放布局动画。时钟使用本机 Arial / Helvetica 无衬线数字，不加载远程字体；日期、辅助文字和输入框占位文字统一使用较深的主题文字色。系统「减少动态效果」偏好和设置中的「减少动画」都会生效。

开发与预览中的 `/api/site-metadata` 由 Vite 中间件提供；打包后的扩展通过后台 Service Worker 读取网页。两者调用相同的真实抓取逻辑，不使用模拟响应或第三方代理。

浏览器能打开网站不代表 Node 开发服务也能连接该网站：两者的网络权限、代理、证书信任与 Cookie 环境可能不同。读取失败时会显示已知的底层错误原因，例如 `EACCES` 表示进程连接被系统或运行环境拒绝，`ENOTFOUND` 表示域名解析失败；此类错误发生在解析网页图标之前。

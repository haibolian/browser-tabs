# 右键菜单与面板交接回归

## 复现与原因

在可聚焦网格的空白处右键，选择「设置」。旧流程中，设置刚出现时可以读到面板，但菜单退出后会把焦点恢复到网格，触发设置抽屉的焦点移出关闭。只检查首次出现的状态会漏掉这个问题。

旧桌面菜单还通过隐藏的 DropdownMenu 触发点定位。关闭时位置被清空为 `(0, 0)`，菜单仍在播放退出动画，因而会跳到左上角。

## 当前交接约定

- 桌面、网站、分组与小组件的右键菜单使用 ContextMenu 的实际触发区域及虚拟鼠标锚点。退出时保留锚点，菜单只淡入淡出。
- 菜单项的 `onAction` 先登记操作；菜单卸载并释放焦点作用域后，再执行操作。选中操作时阻止旧焦点恢复；取消菜单时恢复原焦点，且不滚动页面。
- 右键菜单和按钮下拉菜单共用样式。桌面菜单绑定桌面容器，网站和小组件的菜单阻止冒泡，文本输入保留原生右键行为。
- 桌面通过 `ShortcutCommands` 调用创建和整理操作，分组拖出逻辑单独放在 `folder-dialog.tsx`。
- 拖出弹窗的容错时间为 500ms。移回取消计时，再次移出重新计时；拖拽取消、弹窗卸载时清理计时。弹窗关闭后继续使用已缓存的拖拽来源，直到完成拖放。

## 自动化验证

运行 `pnpm test`、`pnpm lint` 和 `pnpm build`。

`desktop-menu.test.tsx` 在 DOM 环境渲染实际的 SettingsDialog，覆盖网格聚焦后右键打开设置、等待菜单退出并确认焦点仍在面板内，连续执行三轮；同时覆盖新建分组、Escape 取消与输入框右键。

`menu-session.test.ts` 验证操作在焦点释放后执行、取消恢复焦点、操作只执行一次及重新打开时清除旧操作。`drag-exit.test.ts` 验证 499ms 不关闭、500ms 关闭，以及返回、重新移出和取消计时。

网站放置位置与搜索引擎使用 shadcn/Radix Select，自定义弹层通过 Portal 展示，颜色与圆角沿用项目主题。两处均为静态导入。放置位置标签关联触发按钮，桌面选项与分组 ID 使用不同的值前缀。

`shortcut-editor.test.tsx` 覆盖方向键、End、Enter 和 Escape，确认选择后焦点返回触发按钮、Escape 仅关闭选择列表，以及保存后网站正确移入或移出分组。`clock-search.test.tsx` 验证切换搜索引擎不会提交搜索，随后提交使用所选引擎，列表开启时 `/` 不抢占焦点。

## 浏览器验证记录

2026-11-15，在本地开发页面完成以下检查：

| 流程 | 观察结果 |
| --- | --- |
| 网格三个不同空白位置右键 → 设置 → 切换壁纸与常规页签 | 三轮面板均持续显示，菜单已退出，焦点留在设置内 |
| 完整刷新页面后，网格空白右键 → 设置 → 切换页签 | 面板持续显示，菜单已退出，焦点在设置内；本轮无控制台错误或警告 |
| 三个位置打开菜单 → Escape，读取退出阶段坐标 | 开启和关闭阶段坐标一致，未跳到左上角 |
| 桌面菜单 → 添加图标 / 新建分组 | 编辑器保持打开，焦点在对应输入框 |
| 图标右键 → 编辑图标 | 编辑器打开，原菜单退出 |
| 图标布局子菜单 → Escape；小组件右键 → Escape | 子菜单和菜单正常取消，小组件菜单不触发桌面菜单 |
| Shift+F10 | 打开桌面菜单并聚焦菜单项 |
| 拖出分组后及时移回 | 弹窗保持打开 |
| 再次拖出，等待弹窗关闭 → 继续移动 → 放下 | 浮层持续显示，桌面只有一个图标 |
| 图标右键 → 移动到原分组 | 原分组恢复图标，桌面副本移除 |

坐标与动画阶段由浏览器检查；DOM 集成测试负责菜单、面板与焦点交接。详细坐标保存在本地 `artifacts/frontend/menu-regression.json`。
